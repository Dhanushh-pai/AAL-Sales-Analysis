# AAL Sales Analysis – Australia Q4 2020

## Project Overview

This project focuses on analyzing the fourth-quarter sales data of **AAL, an Australian apparel retailer**, to identify sales trends, understand customer-group performance, and evaluate revenue across different Australian states.

The analysis aims to provide data-driven insights that can help the company's Sales and Marketing (S&M) department make informed decisions, identify growth opportunities, and develop strategies for states with lower sales performance.

## Project Objectives

- Analyze sales performance across different Australian states.
- Identify customer groups with the highest and lowest sales.
- Perform data cleaning and handle missing or incorrect values.
- Apply data normalization to prepare the dataset for analysis.
- Generate descriptive statistics for Sales and Unit columns.
- Analyze weekly, monthly, and quarterly sales trends.
- Identify peak and off-peak sales periods.
- Develop visualizations to support business decision-making.
- Provide recommendations based on the analysis.

## Dataset Information

**Dataset:** `AusApparalSales4thQrt2020.csv`

The dataset contains sales information for the fourth quarter of 2020.

| Column | Description |
|---|---|
| Date | Date of the transaction |
| Time | Time of the transaction |
| State | Australian state |
| Group | Customer demographic group |
| Unit | Number of units sold |
| Sales | Total sales amount |

## Project Workflow

### 1. Data Wrangling
- Inspect the dataset and understand its structure.
- Identify missing and incorrect values.
- Handle missing data using appropriate techniques.
- Apply Min-Max normalization to numerical data.
- Explore the use of GroupBy for grouping and summarizing data.

### 2. Data Analysis
- Calculate mean, median, mode, and standard deviation for Sales and Unit.
- Identify customer groups with the highest and lowest sales.
- Compare sales performance across different states.
- Generate weekly, monthly, and quarterly sales reports.

### 3. Data Visualization
- Analyze state-wise sales across Kids, Women, Men, and Seniors groups.
- Compare customer-group sales across states.
- Identify peak and off-peak sales periods.
- Create daily, weekly, monthly, and quarterly visualizations.
- Use box plots and distribution plots to understand sales patterns.

### 4. Business Insights & Recommendations
- Interpret sales trends and customer-group performance.
- Identify states with lower sales and potential growth opportunities.
- Recommend suitable sales and marketing strategies.
- Present findings through visualizations and analytical summaries.
